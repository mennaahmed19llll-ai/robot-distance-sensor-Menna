What Does the Program Do?
This program checks the distances in front of the robot. If the distance is less than 0.5 meters, the robot will STOP. If it is between 0.5 and 1 meter, it will SLOW down. If it is more than 1 meter, it will MOVE.
How Does the Robot Class Work?
The Robot class stores the robot’s name and battery. It also checks the list of distances and gives the correct action for each one.
What Does Each Method Do?
The __init__ method gives the robot a name and battery level.
The process_distances method checks every distance using a loop. It returns STOP, SLOW, MOVE, or ERROR if the value is wrong.
How Do I Run the Code?
I open the robot.py file and run it using Python. The test cases at the bottom will show the results.
